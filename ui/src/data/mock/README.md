# Mock data: where every file comes from

The UI reads only this folder in mock mode (`VITE_DATA_SOURCE=mock`, the default). In api mode the backend files
come from `VITE_API_URL`; `filler/`, `reports/` and `topology.json` are read from here in both modes.

## Copied byte for byte from `out/` (do not hand-edit)

Regenerate with `$env:LLM_OFFLINE="1"; py -3.14 demo.py` in the repo root, then copy `out/*.json` here.

`beat_1.json` … `beat_9.json`, `thread_*.json`, `questions.json`, `notifications.json`, `assertions.json`, `store.json`, `graph.json`.

Within those:

| File | Origin |
|---|---|
| `thread_thread-001.json` (the messages) | **Elisa's own example chat**, `data/elisa_examples/teams_chat.json`, unmodified (dated 1 Nov 2026, synthetic date) |
| `thread_email-001.json` (the message) | **Elisa's own example email**, `data/elisa_examples/email.txt`, unmodified |
| `thread_email-12_barrier.json`, `thread_thread-12b_barrier_update.json` (the messages) | **Generated by `gemini-3.5-flash`** from scenario scripts, hand-edited as listed in `data/DATA_CARD.md` |
| `thread_thread-13_second_technician.json` (Sami's messages) | **Hand-written** for demo beat 7 (synthetic) |
| `thread_thread-14_road_closed.json`, `thread_thread-15_retraction.json` (the messages) | **Hand-written**, no model, for beats 8 and 9 (synthetic; `data/DATA_CARD.md`) |
| Everything the Context layer says (questions, notifications, `agent_text`, `reason`, `action_text`) | Backend output (`demo.py`), never written in the UI |

- `filler/04_chitchat.json` … `filler/10_typos.json`: `data/scenarios/04..10/thread.json`. **Generated by `gemini-3.5-flash`** (hand edits in `data/DATA_CARD.md`). Not ingested by the demo; shown as ordinary chats in "Field chat" with no agent activity.
