# How the build was run

Working documents, kept so the technical decisions can be traced. Nothing here is needed to run the demo.

| File | What it is |
|---|---|
| `HANDOFF.md` | The merged team plan (Mikael and Abhishek), the source of the backend and frontend prompts |
| `MIKAEL_HANDOFF.md` | Mikael's plan, v6, as it stood before the merge |
| `REVIEW_MIKAEL.md`, `REVIEW_ABHISHEK.md` | Each side's review of both plans against Elisa's brief, Friday night |
| `BACKEND_PROMPT.md`, `BACKEND_PROMPT_ADDENDUM.md` | The brief the backend was built from, module by module, with its gates |
| `FRONTEND_PROMPT.md` | The brief for the context map (`frontend-ui/`) |
| `TEAMS_CLONE_HANDOFF.md` | The brief for the Teams clone (`ui/`), including the data shapes it reads |
| `GATES.md` | The gate commands run overnight, re-runnable |
| `MORNING_REPORT.md` | The state of the backend on Saturday morning |
| `TRANSCRIPT_RECORDING.md`, `TRANSCRIPT_RECORDING_raw.md` | Elisa's briefing and Q&A, transcribed from an audience recording |

Elisa staff are named only in Elisa's own material (`challenge/`, the transcripts); in our own notes they appear by role.
